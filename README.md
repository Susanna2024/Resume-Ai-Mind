# 🚀 ResumAiMind
🌐 Live Demo: https://resum-ai-mind.onrender.com/

> AI-powered job match analyzer and career coach — open source, multilingual.

Paste a CV and a job description and get an honest, scored compatibility analysis. Or switch
to **Career Coach** mode and get a full growth plan: strengths, gaps, suggested roles, and a
30/60/90-day action plan — all generated by LLMs (Groq & OpenAI), not templated advice.

> Built as a hands-on project to demonstrate practical LLM application development: prompt
> design, structured JSON generation, and a full-stack monorepo app shipped end to end.

## Features

**Match Analysis**
- Upload a CV and paste a job description
- Scored match with a transparent rubric breakdown (technical skills, nice-to-have, experience, soft skills)
- Matching vs. missing skills, an honest summary, CV suggestions, and likely interview questions

**Career Coach**
- Analyzes a CV on its own, with an optional target role
- Returns concrete strengths and growth areas
- Suggested roles that fit the candidate's background
- A 30/60/90-day action plan
