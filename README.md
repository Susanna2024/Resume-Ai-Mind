# RESUMAIMIND

**AI-powered job match analyzer and career coach** — multilingual (EN/ES/IT).

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://resum-ai-mind.onrender.com/)
[![License](https://img.shields.io/badge/license-All%20Rights%20Reserved-lightgrey.svg)](./LICENSE)
[![React](https://img.shields.io/badge/frontend-React%2019-61DAFB)](./frontend)
[![FastAPI](https://img.shields.io/badge/backend-FastAPI-009688)](./backend)

**[Try it live →](https://resum-ai-mind.onrender.com/)** (free tier — the server may take ~30s to
wake up on first load)

Paste a CV and a job description and get an honest, scored compatibility analysis. Or switch
to **Career Coach** mode and get a full growth plan: strengths, gaps, suggested roles, and a
30/60/90-day action plan — all generated by an LLM, not templated advice.

> Built as a hands-on portfolio project to demonstrate practical LLM application development:
> prompt design, structured JSON generation, and a full-stack app shipped end to end (including
> a live production deploy). Source is public for review; see [License](#license).

## Features

**Match Analysis**
- Upload a CV (PDF, parsed client-side) and paste a job description
- Scored match (0–100) with a transparent rubric breakdown (technical skills, nice-to-have,
  experience, soft skills)
- Matching vs. missing skills, an honest summary, CV suggestions, and likely interview questions

**Career Coach**
- Analyzes a CV on its own, with an optional target role
- Returns concrete strengths and growth areas (grounded in what's actually on the CV, not
  generic advice)
- Suggested roles that fit the candidate's background
- A 30/60/90-day action plan
- Recommended resources (courses, books, projects) tied to specific growth areas

## Getting started (development)

Run backend and frontend separately, with hot-reload on both:

### Backend

```bash
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env      # then add your GROQ_API_KEY
uvicorn app.main:app --reload
```

Runs on `http://127.0.0.1:8000`. Get a free API key at [console.groq.com](https://console.groq.com).

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Runs on `http://127.0.0.1:5173` and proxies `/api` requests to the backend automatically
(see `vite.config.ts`) — no extra configuration needed.

## Running as a single combined service

This is how the [live demo](https://resum-ai-mind.onrender.com/) is deployed: FastAPI serves the
built frontend directly, one process, one port, no CORS to configure.

```bash
cd frontend && npm run build && cd ..
cd backend && uvicorn app.main:app --port 8000
```

Open `http://127.0.0.1:8000` — the full app (UI + API) is served from there.

## Environment variables

**backend/.env**

| Variable | Description | Default |
|---|---|---|
| `GROQ_API_KEY` | Your Groq API key | — (required) |
| `ALLOWED_ORIGINS` | Comma-separated list of allowed CORS origins (only matters if frontend and backend are on different domains) | `http://localhost:3000,http://localhost:5173` |

**frontend/.env** — not needed for local dev or a combined deployment. Only set
`VITE_API_URL` if the frontend is deployed on a different domain than the backend
(see `.env.example`).

## API reference

```
POST /api/analyze
{ "cv_text": "...", "job_text": "...", "language": "en" }

POST /api/coach
{ "coach_context": { ... }, "target_role": "", "language": "en" }

GET /health   — health check, useful for uptime monitoring on free hosting tiers
```

## Deployment

Deployed on [Render](https://render.com) as a single service (see `render.yaml`):
- Build: builds the frontend, then installs backend dependencies
- Start: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
- Env vars: `GROQ_API_KEY`

Same repo also works as two separate services if you'd rather scale frontend and backend
independently — deploy `frontend` to Vercel/Netlify with `VITE_API_URL` pointing at the
backend, and `backend` to Render/Railway with `ALLOWED_ORIGINS` pointing at the frontend.
